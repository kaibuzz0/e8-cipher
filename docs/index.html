Current conclusion: the legacy v2 cipher is a documented broken-design specimen, not a secure encryption protocol. Gate 0 mathematics is verified; the project is now defining the threat model and deciding whether E8 belongs in any defensible successor construction.

Verified negative results from legacy v2

Cross-key isolation fails. Unrelated keys share the effective decoding basis, and one unrelated key can decrypt another key's ciphertext in the regression suite.
Encryption randomness is reused. Repeated encryption restarts the same secret-derived PRNG stream, producing identical masks/noise and deterministic ciphertext for the same message.
Ciphertext subtraction leaks message differences. Equal-length ciphertexts cancel the reused lattice term and Gaussian noise.
The legacy nonce is not a nonce. It is a constant prefix derived from private seed material.

These failures are preserved as tests so future work cannot confuse successful round-trip decryption with security. The public compatibility wrapper now emits a visible security warning when instantiated.

Research gates

Gate 0 — Genuine E8 mathematics
Complete: 240 roots, exact determinant/Gram checks, full Weyl root closure, and E8^N direct-sum invariants verified.
Gate 1 — Legacy failure containment
Captured catastrophic v2 flaws as regression evidence and marked the compatibility API insecure.
Gate 2 — Threat model & construction
Specify security goals and decide where E8 belongs: trapdoor, LWE/Module-LWE geometry, coding layer, or nowhere.
Gate 3 — Reference implementation
Only after Gate 2: build a candidate protocol with CSPRNG randomness, strict serialization, and deterministic test vectors.
Gate 4 — Adversarial verification
Known-plaintext, cross-key, randomness-reuse, lattice-reduction, fuzzing, and statistical attacks.
Gate 5 — Review readiness
Formal specification, concrete attack estimates, benchmarks, side-channel analysis, and independent review.

Verified mathematical substrate

True E8 roots

The active research module constructs all 240 E8 roots explicitly rather than using eight simplified directions.

Exact arithmetic

Root membership, norms, basis determinant, Gram determinant, and Weyl closure are checked in scaled integer coordinates.

E8^N direct sums

Higher-dimensional objects are explicit block-diagonal direct sums with tested dimensions, covolume behavior, embedded roots, and block-local reflections.

Repository map

research/e8_lattice.py contains the verified E8 substrate. tests/test_e8_lattice.py checks mathematical invariants. tests/test_legacy_failures.py preserves verified v2 failures. RESEARCH_PLAN.md is the pass-to-pass research gate checklist. Legacy e8_core.py and e8_cipher.py remain only for historical reproduction and regression evidence.
